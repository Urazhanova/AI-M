## Проверка усвоения

### Знание (Knowledge)
- Какие этапы включает AI-трансформация?
- В чем заключается роль структуры данных в AI-трансформации?

### Понимание (Comprehension)
- Объясните, почему важно демонстрировать быструю выгоду от AI.
- Приведите пример простой автоматизации, которая может показать возвратные инвестиции.

### Применение (Application)
- Опишите сценарий внедрения автоматизации в отделе продаж.
- Как можно использовать AI для управления проектами?

### Анализ (Analysis)
- Сравните этапы создания автоматизаций и цепочек автоматизаций.
- Разложите на части процесс AI-трансформации в компании.

### Синтез (Synthesis)
- Предложите решение для автоматизации процесса запуска нового продукта.
- Соберите новую цепочку автоматизаций для оптимизации бизнес-процесса.

### Оценка (Evaluation)
- Оцените эффективность AI-трансформации на примере успешного кейса.
- Обоснуйте необходимость изменений подходов к управлению в процессе AI-трансформации.

## Definition of Done

### Минимальный DoD (Bloom 1-3)
- Успешно внедрена простая автоматизация, демонстрирующая выгоду.
- Создана структура данных для поддержки AI-процессов.

### Полный DoD (Bloom 4-6)
- Проанализирована и улучшена существующая автоматизация.
- Разработана и внедрена новая цепочка автоматизаций.
