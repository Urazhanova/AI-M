## Проверка усвоения

### Знание (Knowledge)
- Какие проблемы возникают при хранении данных в формате Markdown?
- Какие ограничения имеют векторные базы данных?

### Понимание (Comprehension)
- Объясните, почему гибридные системы могут быть более эффективными.
- Приведите пример использования автоматизации в управлении данными.

### Применение (Application)
- Опишите сценарий, в котором использование гибридной системы будет наиболее целесообразным.
- Как можно использовать скрипты для поддержания актуальности данных?

### Анализ (Analysis)
- Сравните преимущества и недостатки Markdown и векторных баз данных.
- Разложите на части процесс автоматизации управления данными.

### Синтез (Synthesis)
- Предложите решение для улучшения поиска информации в Markdown файлах.
- Разработайте план автоматизации обновления данных.

### Оценка (Evaluation)
- Оцените эффективность использования гибридных систем в вашей организации.
- Обоснуйте необходимость автоматизации процессов в управлении данными.

## Definition of Done

### Минимальный DoD (Bloom 1-3)
- Составить список проблем, связанных с хранением данных в Markdown.
- Применить скрипт для автоматизации обновления данных.

### Полный DoD (Bloom 4-6)
- Провести анализ эффективности гибридных систем на основе конкретных данных.
- Разработать и внедрить план автоматизации управления данными.
